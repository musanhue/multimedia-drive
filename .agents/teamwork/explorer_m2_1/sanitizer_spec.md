## 1. Executive Summary

In media streaming architectures (such as Multimedia Drive for Samsung Smart TV UN50NU7400), media files stored in cloud providers like Google Drive reflect diverse, unstandardized naming conventions generated by scene encoders, P2P releases, and personal library ripping tools. Unsanitized raw filenames (e.g., `Inception.2010.1080p.BluRay.x264-SPARKS.mkv`, `Blade.Runner.2049.2017.2160p.UHD.HDR.x265-GROUP.mkv`) cannot be passed directly to The Movie Database (TMDB v3) API, as technical noise tokens and scene tags trigger query mismatches and zero search results.

This document defines the exact architecture, technical interface, 8-stage pipeline, noise dictionary, and comprehensive unit test suite for `server/metadata/sanitizer.ts`. The implementation guarantees:
1. Deterministic extraction of clean titles and 4-digit release years (1900–2099).
2. Advanced disambiguation of numeric titles (e.g. `Blade Runner 2049 (2017)`, `2001: A Space Odyssey (1968)`, `1917 (2019)`).
3. Television show series and episode detection across multiple conventions (`S01E02`, `1x02`, `Season 1 Episode 2`, `Temporada 1 Episodio 2`).
4. Strict preservation of Spanish diacritics (`á, é, í, ó, ú, ñ, ü, ¿, ¡`).
5. Preservation of compound words with hyphens (`Spider-Man`, `WALL-E`, `X-Men`).
6. Zero catastrophic backtracking (`O(N)` linear regex performance, <50ms execution on >250 char inputs).

## 3. The 8-Stage Sanitization Pipeline

```
Raw Filename 
   │
   ▼
[Stage 0: Unicode NFC Normalization] (e.g. normalize decomposed accents)
   │
   ▼
[Stage 1: File Extension Stripping] (.mkv, .mp4, etc., guarding .2049)
   │
   ▼
[Stage 2: TV Episode & Series Detection] (S01E02, 1x02, Season 1 Episode 2, Temporada...)
   │
   ▼
[Stage 3: Release Year Extraction] (Lookahead 1900-2099; disambiguate title numbers)
   │
   ▼
[Stage 4: Noise Tag Stripping] (Convergence loop with classified dictionary)
   │
   ▼
[Stage 5: Delimiter Translation & Hyphen Preservation] (Dots/underscores to spaces, keep Spider-Man)
   │
   ▼
[Stage 6: Bracket & Release Group Pruning] (Clean empty brackets, strip trailing -SPARKS)
   │
   ▼
[Stage 7: Spanish Diacritics & Punctuation Guard] (Preserve ñ, á, é, í, ó, ú, ü, ¿, ¡)
   │
   ▼
[Stage 8: Whitespace Normalization & Fallback] (Collapse spaces, restore pure numeric titles)
```

### Stage 1: File Extension Stripping
- **Purpose**: Strip video container, audio, and subtitle extensions.
- **Critical Edge Case**: Guard against stripping 4-digit numeric titles as file extensions (e.g. `Blade.Runner.2049` or `1984`).
- **Regex Implementation**:
  ```typescript
  // Matches 2-5 character extension preceded by a dot, UNLESS the extension is a 4-digit year (19xx/20xx)
  base = base.replace(/\.(?!(?:19\d{2}|20\d{2})$)[a-zA-Z0-9]{2,5}$/, '');
  ```
- **Supported Formats**: `.mkv`, `.mp4`, `.avi`, `.mov`, `.wmv`, `.flv`, `.webm`, `.m4v`, `.ts`, `.m2ts`, `.vob`, `.ogv`, `.3gp`, `.iso`, `.mp3`, `.flac`, `.aac`, `.wav`, `.m4a`, `.ogg`, `.srt`, `.vtt`.

### Stage 2: TV Show Detection (Series & Episode Extraction)
- **Purpose**: Detect whether media is a TV series episode, extract integer `season` and `episode`, and isolate the series title prefix.
- **Supported Patterns**:
  1. Scene standard: `S01E02`, `s04e09`, `S1E2`
  2. European/Latin cross notation: `1x02`, `4x08`
  3. Verbose English: `Season 1 Episode 2`, `Season.1.Episode.05`
  4. Verbose Spanish: `Temporada 1 Episodio 2`, `Temporada.12.Episodio.03`
  5. Short Spanish: `T01E02`, `T2E4`
  6. Multi-episode notation: `S01E01-E02` (extracts first episode)
  7. Long series / Anime: Supports 3-digit episode numbers (`S01E105`, `1x105`).
- **Resolution Conflict Prevention**:
  Standard video dimensions (e.g., `1920x1080` or `720x480`) must NOT trigger `4x08` matching. This is prevented by enforcing `\d{1,2}` (maximum 2 digits) for the season number before `x`.
- **Regex Implementation**:
  ```typescript
  const tvPattern = /(?:[._\s\(\[-]|^)(?:(?:s|t|season|temporada)[._\s-]*(\d{1,2})[._\s-]*(?:e|ep|episode|episodio)[._\s-]*(\d{1,3})|(\d{1,2})x(\d{1,3}))(?:[._\s\)\]-]|$)/i;
  const match = base.match(tvPattern);
  if (match) {
    isSeries = true;
    season = parseInt(match[1] || match[3], 10);
    episode = parseInt(match[2] || match[4], 10);
    // Isolate title prefix occurring before the TV episode marker
    base = base.substring(0, match.index);
  }
  ```

### Stage 3: Release Year Extraction (1900–2099) with Regex Lookahead
- **Purpose**: Extract the authentic 4-digit release year without consuming adjacent delimiters or prematurely swallowing numbers that belong to the movie title.
- **The Lookahead Requirement**:
  When two consecutive year-like numbers or tokens are separated by a single dot (e.g. `Blade.Runner.2049.2017.mkv`), consuming the delimiter after `2049` leaves no delimiter for `2017`. Using regex lookahead `(?=[._\s\)\]-]|$)` ensures the trailing delimiter is inspected without being consumed.
- **Disambiguation Logic for Numeric Titles**:
  1. Find all 4-digit numbers in the range `1900` to `2099`.
  2. If multiple years exist (e.g. `Blade Runner 2049 2017`, `2001 A Space Odyssey 1968`, `Wonder Woman 1984 2020`):
     - The LAST occurrence preceding the technical tags is the actual release year (`2017`, `1968`, `2020`).
     - Preceding numbers remain part of the title (`Blade Runner 2049`, `2001 A Space Odyssey`, `Wonder Woman 1984`).
  3. If only ONE year exists at index 0 followed by title text (e.g. `2001.A.Space.Odyssey.mkv` without a separate release year):
     - `2001` is part of the title and NOT stripped as the release year.
  4. If only ONE year exists at index 0 and nothing else follows (e.g. `1984.mkv` or `1917.mkv`):
     - `year` is set to `1984` or `1917`, and `cleanTitle` is preserved as `'1984'` or `'1917'`.
  5. When cutting the base title at the release year:
     - Opening parentheses/brackets immediately preceding the year (e.g. `(2009)` or `[2009]`) are included in the cut so no dangling bracket remains.
- **Regex Implementation**:
  ```typescript
  const yearMatches: Array<{ year: number; rawIndex: number; yearIndex: number }> = [];
  const yearRegex = /(?:^|[._\s\(\[-])(19\d{2}|20\d{2})(?=[._\s\)\]-]|$)/g;
  let m: RegExpExecArray | null;
  while ((m = yearRegex.exec(base)) !== null) {
    yearMatches.push({
      year: parseInt(m[1], 10),
      rawIndex: m.index,
      yearIndex: m.index + (m[0].length - m[1].length)
    });
  }

  if (yearMatches.length > 0) {
    const lastYear = yearMatches[yearMatches.length - 1];
    const isSingleYearAtStartWithText = yearMatches.length === 1 &&
      lastYear.rawIndex === 0 &&
      base.length > 4 &&
      /[a-zA-Z]/.test(base.substring(4));

    if (!isSingleYearAtStartWithText) {
      year = lastYear.year;
      let cutIdx = lastYear.yearIndex;
      if (cutIdx > 0 && /[\(\[\{]/.test(base[cutIdx - 1])) {
        cutIdx--;
      }
      const candidateTitle = base.substring(0, cutIdx).trim();
      if (candidateTitle.length > 0 || yearMatches.length > 1) {
        base = candidateTitle;
      }
    }
  }
  ```

### Stage 4: Noise Tag Stripping & Dictionary
- **Purpose**: Remove all resolution, audio, video codec, release source, edition, language, and release group markers.
- **Convergence Loop**: Multiple noise tokens often appear consecutively (e.g. `.1080p.BluRay.x264.DTS-HD.MA.5.1.`). A single regex pass can leave boundary artifacts. The engine executes in a `do ... while (cleaned !== prev)` loop until the string stabilizes.
- **ReDoS Prevention**: Token patterns are strictly bounded by delimiter sets `(?:[._\s\(\[-]|^)` and `(?:[._\s\)\]-]|$)`. Tokens containing special regex characters (`.`, `+`) are properly escaped (`h\\.264`, `dd\\+`, `hdr10\\+`).

### Stage 5: Delimiter Translation & Hyphen Preservation
- **Purpose**: Translate dots (`.`) and underscores (`_`) into clean spaces, while preserving compound word hyphens (`Spider-Man`, `WALL-E`, `X-Men`, `Jean-Luc`).
- **Compound Word Preservation Rule**:
  Hyphens connecting letters or digits directly (`[a-zA-Z0-9]-[a-zA-Z0-9]`) with no surrounding spaces are strictly preserved.
- **Delimiter Dash Removal Rule**:
  Hyphens surrounded by spaces (`\s+-\s+`), preceded by space (`\s+-`), followed by space (`-\s+`), or standing at boundaries are stripped.
- **Implementation**:
  ```typescript
  cleaned = cleaned.replace(/[._]/g, ' ');
  cleaned = cleaned.replace(/\s+-\s+/g, ' ');
  cleaned = cleaned.replace(/\s+-(?=[^\w]|$)/g, ' ');
  cleaned = cleaned.replace(/(?:^[^\w]|(?<=\s))-+/g, ' ');
  ```

---

### Stage 6: Bracket & Release Group Pruning
- **Purpose**: Eliminate empty bracket pairs left behind by noise stripping (`[]`, `()`, `{}`) and prune trailing scene tags.
- **Implementation**:
  ```typescript
  // Remove empty or whitespace-only brackets
  cleaned = cleaned.replace(/\[\s*\]|\(\s*\)|\{\s*\}/g, ' ');
  // Remove trailing hyphen-prefixed group tags (e.g., -SPARKS, -RARBG)
  cleaned = cleaned.replace(/-[a-zA-Z0-9]+$/, '');
  ```

---

### Stage 7: Spanish Diacritics & Punctuation Guard
- **Purpose**: Preserve Spanish and European characters intact:
  - Vowels with acute accents: `á`, `é`, `í`, `ó`, `ú`, `Á`, `É`, `Í`, `Ó`, `Ú`
  - Vowels with diaeresis: `ü`, `Ü`
  - Eñe: `ñ`, `Ñ`
  - Spanish inverted punctuation marks: `¿`, `¡`
- **Constraint**:
  Never use destructive ASCII regexes like `replace(/[^\w\s]/g, '')`, which irreversibly destroys Spanish titles (`Amélie` -> `Amlie`, `Año Uno` -> `Ao Uno`, `El laberinto del fauno` -> `El laberinto del fauno`).
- **Sanitization Rule**:
  Only strip non-alphanumeric punctuation outside the valid Unicode Spanish set:
  ```typescript
  cleaned = cleaned.replace(/^[^\wáéíóúÁÉÍÓÚñÑüÜ¿¡]+|[^\wáéíóúÁÉÍÓÚñÑüÜ!?)]+$/g, '');
  ```

---

### Stage 8: Whitespace Normalization & Fallback Logic
- **Purpose**: Collapse consecutive spaces into a single space, trim margins, and provide deterministic fallback values.
- **Fallback Logic**:
  1. If `cleanTitle` is reduced to an empty string because the filename was purely a numeric title (e.g. `1984.mkv` or `1917.mkv`), restore the year as the title.
  2. If the filename was purely noise tokens (e.g. `1080p.x264.BluRay.mkv`), return `""` safely without throwing an error (satisfying acceptance criterion F6-B01).
- **Implementation**:
  ```typescript
  cleaned = cleaned.replace(/\s+/g, ' ').trim();

  if (!cleaned && year !== null && filename.startsWith(String(year))) {
    cleaned = String(year);
  }
  ```

```typescript
/**
 * Strips container, video, audio, and subtitle extensions.
 * Guards against stripping 4-digit years like .2049.
 */
export function stripFileExtension(filename: string): string {
  return filename.replace(/\.(?!(?:19\d{2}|20\d{2})$)[a-zA-Z0-9]{2,5}$/, '');
}

/**
 * Detects TV Series patterns: S01E02, 1x02, Season 1 Episode 2, Temporada 1 Episodio 2, T01E02.
 */
export function detectTvEpisode(base: string): {
  isSeries: boolean;
  season: number | null;
  episode: number | null;
  titleBase: string;
} {
  const tvPattern = /(?:[._\s\(\[-]|^)(?:(?:s|t|season|temporada)[._\s-]*(\d{1,2})[._\s-]*(?:e|ep|episode|episodio)[._\s-]*(\d{1,3})|(\d{1,2})x(\d{1,3}))(?:[._\s\)\]-]|$)/i;
  const match = base.match(tvPattern);
  if (match) {
    const season = parseInt(match[1] || match[3], 10);
    const episode = parseInt(match[2] || match[4], 10);
    const titleBase = base.substring(0, match.index);
    return { isSeries: true, season, episode, titleBase };
  }
  return { isSeries: false, season: null, episode: null, titleBase: base };
}

/**
 * Extracts 4-digit release year (1900-2099) using regex lookahead.
 */
export function extractReleaseYear(base: string): {
  year: number | null;
  titleBase: string;
} {
  let year: number | null = null;
  const yearMatches: Array<{ year: number; rawIndex: number; yearIndex: number }> = [];
  const yearRegex = /(?:^|[._\s\(\[-])(19\d{2}|20\d{2})(?=[._\s\)\]-]|$)/g;
  let m: RegExpExecArray | null;

  while ((m = yearRegex.exec(base)) !== null) {
    yearMatches.push({
      year: parseInt(m[1], 10),
      rawIndex: m.index,
      yearIndex: m.index + (m[0].length - m[1].length)
    });
  }

  let titleBase = base;
  if (yearMatches.length > 0) {
    const lastYear = yearMatches[yearMatches.length - 1];
    const isSingleYearAtStartWithText = yearMatches.length === 1 &&
      lastYear.rawIndex === 0 &&
      base.length > 4 &&
      /[a-zA-Z]/.test(base.substring(4));

    if (!isSingleYearAtStartWithText) {
      year = lastYear.year;
      let cutIdx = lastYear.yearIndex;
      if (cutIdx > 0 && /[\(\[\{]/.test(base[cutIdx - 1])) {
        cutIdx--;
      }
      const candidate = base.substring(0, cutIdx).trim();
      if (candidate.length > 0 || yearMatches.length > 1) {
        titleBase = candidate;
      }
    }
  }

  return { year, titleBase };
}

/**
 * Iteratively removes technical noise tokens using classified dictionary.
 */
export function stripNoiseTags(text: string): string {
  let cleaned = text;
  let prev: string;
  do {
    prev = cleaned;
    cleaned = cleaned.replace(NOISE_REGEX, ' ');
  } while (cleaned !== prev);
  return cleaned;
}

/**
 * Normalizes delimiters, preserves compound hyphens, cleans brackets and release groups.
 */
export function cleanDelimitersAndHyphens(text: string): string {
  let cleaned = text;
  // Clean empty brackets
  cleaned = cleaned.replace(/\[\s*\]|\(\s*\)|\{\s*\}/g, ' ');
  // Dots and underscores to spaces
  cleaned = cleaned.replace(/[._]/g, ' ');
  // Remove hyphens surrounded by spaces or isolated delimiters, keeping compound words like Spider-Man
  cleaned = cleaned.replace(/\s+-\s+/g, ' ');
  cleaned = cleaned.replace(/\s+-(?=[^\w]|$)/g, ' ');
  cleaned = cleaned.replace(/(?:^[^\w]|(?<=\s))-+/g, ' ');
  // Prune trailing hyphen release group
  cleaned = cleaned.replace(/-[a-zA-Z0-9]+$/, '');
  // Trim outer non-alphanumeric punctuation, preserving Spanish inverted marks
  cleaned = cleaned.replace(/^[^\wáéíóúÁÉÍÓÚñÑüÜ¿¡]+|[^\wáéíóúÁÉÍÓÚñÑüÜ!?)]+$/g, '');
  // Collapse whitespace
  return cleaned.replace(/\s+/g, ' ').trim();
}

/**
 * Main 8-stage sanitization function.
 */
export function sanitizeMediaFilename(filename: string): SanitizedMediaInfo {
  if (!filename || typeof filename !== 'string') {
    return {
      originalFilename: String(filename || ''),
      cleanTitle: '',
      year: null,
      isSeries: false,
      season: null,
      episode: null
    };
  }

  // Stage 0: Unicode NFC normalization
  let base = filename.normalize('NFC').trim();

  // Stage 1: Strip extension
  base = stripFileExtension(base);

  // Stage 2: TV Show Detection
  const tvResult = detectTvEpisode(base);
  const isSeries = tvResult.isSeries;
  const season = tvResult.season;
  const episode = tvResult.episode;
  base = tvResult.titleBase;

  // Stage 3: Release Year Extraction
  const yearResult = extractReleaseYear(base);
  const year = yearResult.year;
  base = yearResult.titleBase;

  // Stage 4: Noise Tag Stripping
  base = stripNoiseTags(base);

  // Stages 5-7: Delimiter, Hyphen, Bracket, and Diacritic normalization
  let cleanTitle = cleanDelimitersAndHyphens(base);

  // Stage 8: Fallback for pure numeric titles (e.g. "1984.mkv")
  if (!cleanTitle && year !== null && filename.startsWith(String(year))) {
    cleanTitle = String(year);
  }

  return {
    originalFilename: filename,
    cleanTitle,
    year,
    isSeries,
    season,
    episode
  };
}
```

## 7. Integration & Downstream Compatibility

### 7.1 Backend API Endpoint: `GET /api/metadata/clean-title`
In `server/routes/metadata.ts` (or `server/routes/drive.ts`), the route handler exposes the sanitizer as:
```typescript
import { Router } from 'express';
import { sanitizeMediaFilename } from '../metadata/sanitizer';

const router = Router();

router.get('/clean-title', (req, res) => {
  const filename = String(req.query.filename || '');
  const result = sanitizeMediaFilename(filename);
  return res.json(result);
});

export default router;
```
This guarantees 100% compliance with Tier 1 E2E tests (`tests/e2e/tier1-feature-coverage/f06-filename-regex-cleaning.test.js`) and Tier 2 boundary tests (`tests/e2e/tier2-boundary-corner/f06-regex-boundaries.test.js`).

### 7.2 TMDB Enricher Integration
In `server/metadata/tmdb.ts`, the TMDB search client consumes the output of `sanitizeMediaFilename`:
- If `isSeries: true`:
  - Query: `https://api.themoviedb.org/3/search/tv?query=${encodeURIComponent(cleanTitle)}&first_air_date_year=${year || ''}&language=es-ES`
- If `isSeries: false`:
  - Query: `https://api.themoviedb.org/3/search/movie?query=${encodeURIComponent(cleanTitle)}&year=${year || ''}&language=es-ES`
  - Fallback 1: If 0 results, retry without year.
  - Fallback 2: If 0 results and title contains parentheses (e.g. `(Pan's Labyrinth)`), strip parenthetical phrase and retry core title.

### 7.3 Compliance with Isolation Barrier (R2 / F8)
The sanitization engine is purely functional and stateless. It has no network dependencies and never contacts TMDB. The isolation gate in `server/metadata/resolver.ts` checks folder category: if the media belongs to `Videos familiares`, TMDB enrichment is completely bypassed, and the sanitized title or Drive native metadata is served directly.
